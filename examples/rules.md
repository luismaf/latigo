# House rules

Appended verbatim to every whip. Standing rules belong in a file, not
hardcoded in the tool — they change per project and per week.

Examples of what earns a place here:

- Do not run the full test suite; verify with a targeted check instead.
- Only the supervisor compiles: report your errors, do not build.
- New code and comments in English.
- Commit with explicit paths; the tree is shared with other workers.
